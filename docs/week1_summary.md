# Hamming Code Reading Notes

- Problem: Digital data can be corrupted by bit flips.
- Method: Redundant parity bits allow detection and correction of certain errors.
- Key idea: The syndrome identifies the position of a single-bit error.
- Use in Project A: I will extend this idea to a (39,32) SECDED code.
- Open question: How does the overall parity bit distinguish single and double errors?
